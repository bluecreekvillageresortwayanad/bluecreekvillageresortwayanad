# Blue Creek Village Resort — Wayanad booking website

A responsive static website for Blue Creek Village Resort, built with HTML, CSS and JavaScript. It uses the supplied resort photographs and includes accommodation cards, resort experiences, a gallery, rain ambience controls, a booking request form, and a simple local-device review demo.

## Accommodation details added
- 2 couple cottages
- 1 three-bedroom (3BHK) A-frame
- 5 tents
- 1 double-bed villa
- Total stated resort capacity: up to 40 guests

Individual room/tent occupancy, facilities, prices, and inclusions are not assumed by the site; guests are prompted to confirm these directly with the resort.

## How to use
1. Extract the ZIP file.
2. Open `index.html` in a modern browser, or upload the folder to a static web host.
3. Booking requests open WhatsApp with the guest's dates, guest count and preferred stay type pre-filled for **+91 80754 18509**. The guest must still tap Send in WhatsApp; this is not an automatic confirmed reservation.

## Notes
- The rain ambience is generated by the browser using Web Audio. Most browsers block autoplay with sound until a visitor interacts with the page, so use the floating sound button if needed.
- Reviews entered in the page are stored only in that browser/device (`localStorage`). They are not shared with other visitors. A backend/database or review service is needed for public reviews.
- The page uses HTML/CSS/JavaScript and does not require Java to run as a static website.


Page order: the booking section appears before the reviews section, so guest reviews are the final main section before the footer.


Recent updates: booking and review sections have exchanged positions; booking allows up to 40 adults and 20 children as individual selector limits, while enforcing a maximum of 40 guests combined. Reviews saved on this browser can be edited or deleted using the buttons on each review card. These reviews remain local to that browser/device.

Recent update: The 3BHK A-Frame accommodation card now has a six-photo catalogue using the newly supplied exterior and interior photos. Use the left/right arrow buttons to browse the images. The header “Book Now” link has a green square-corner button background.
